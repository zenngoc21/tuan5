# Câu 6 — phiên bản chạy độc lập

**Đáp ứng:** RefreshControl, finally dừng tải, giữ nguyên tùy chọn, nội dung rỗng.

## Chạy
1. Dán URL resource `movies` trên MockAPI vào `API_URL` trong `App.tsx`.
2. Chạy `npm install` rồi `npx expo start` trong chính thư mục `Cau6`.
3. Hoặc tạo Snack TypeScript và chép `App.tsx` cùng `components/MovieCard.tsx` (nếu có).
4. Không chép `node_modules` hay chuyển sang JavaScript: đề yêu cầu TypeScript.

**Lưu ý:** Không có API thật, phần hiển thị danh sách không thể có dữ liệu từ máy chủ.
